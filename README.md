# Ashish Chandra Academic Website

This folder contains a deployment-ready static academic website.

## Files
- `index.html` — website content
- `styles.css` — responsive design
- `script.js` — mobile navigation + dynamic copyright year
- `Ashish_Chandra_CV.pdf` — downloadable CV

## Fastest deployment options

### GitHub Pages
1. Create a GitHub repository, for example `profashishchandra`.
2. Upload these files to the repository root.
3. In GitHub: Settings → Pages → Deploy from branch → `main` / root.
4. GitHub gives you a public URL.
5. Add a custom domain such as `profashishchandra.com` in the Pages settings.

### Netlify
1. Go to Netlify.
2. Drag and drop this entire folder into the deployment area.
3. Connect your custom domain afterward.

### Cloudflare Pages
Create a Pages project, upload/connect the folder/repository, then attach your domain.
