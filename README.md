# Ashish Chandra Academic Website

This repository is configured to use the **Academic Pages** GitHub Pages repository as a remote Jekyll theme.

## Deployment

1. Remove the old standalone HTML files from the existing `ProfAshishChandra.github.io` repository.
2. Upload **all files and folders in this package**, preserving the directory structure.
3. In GitHub: **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. The site URL is: https://ProfAshishChandra.github.io

The sidebar intentionally includes only:
- Name/photo
- Short academic bio
- Normal, Illinois, USA
- Illinois State University
- Email
- Google Scholar
- CV

GitHub and ORCID are intentionally omitted.

The Research page intentionally uses **no research-area images**.
